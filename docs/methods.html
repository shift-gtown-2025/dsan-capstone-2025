Methods

Overview

This section documents the comprehensive methodology for store clustering analysis, including feature engineering, preprocessing strategies, clustering algorithm selection, and robustness evaluation. The analysis systematically compares multiple approaches to identify the optimal clustering solution that meets business requirements.

1. Feature Engineering

1.1 Feature Selection

For clustering analysis, we selected 11 key features that capture different aspects of store performance:

Core Business Metrics (7 features): - sales_mean: Average monthly sales - total_ad_spend_mean: Average monthly ad spend - roas_mean: Return on ad spend - conversion_rate_mean: Conversion rate - website_visits_mean: Average website visits - search_spend_ratio_mean: Search ad spend ratio - social_spend_ratio_mean: Social ad spend ratio

Enhanced Ad Activity Metrics (4 features): - ad_months_active: Number of months with ad activity - ad_active_ratio: Ratio of months with ad activity - spent_any: Binary indicator of any ad spend - avg_ad_spend_active_only: Average ad spend for active months only

2. Preprocessing Methods Comparison

2.1 Preprocessing Pipeline Components

We systematically tested different combinations of preprocessing components:

Scalers: - MinMaxScaler: Scales features to [0, 1] range - RobustScaler: Uses median and IQR, robust to outliers - QuantileTransformer: Maps features to uniform or normal distribution - PowerTransformer: Applies Yeo-Johnson transformation

Outlier Handling: - IsolationForest: Identifies and removes outliers (contamination=0.08)

Dimensionality Reduction: - PCA: Principal Component Analysis (95% variance retention) - VarianceThreshold: Removes low-variance features

Feature Weighting: - Uniform weights - Activity features weighted 2x or 3x

3. Clustering Algorithm Comparison

3.1 Clustering Algorithms Tested

We evaluated multiple clustering algorithms:

Partitioning Methods: - KMeans: Centroid-based, stable and interpretable - GMM (Gaussian Mixture Model): Soft clustering, probabilistic assignments

Density-Based Methods: - DBSCAN: Flexible cluster shapes, handles noise

Graph-Based Methods: - Spectral Clustering: Uses graph Laplacian, good for non-convex clusters

def evaluate_clustering(X, labels):
    """Evaluate clustering performance"""
    n_clusters = len(set(labels)) - (1 if -1 in labels else 0)
    if n_clusters < 2:
        return None
    
    # Filter noise points for DBSCAN
    if -1 in labels:
        mask = labels != -1
        if mask.sum() < 2:
            return None
        X_eval, y_eval = X[mask], labels[mask]
    else:
        X_eval, y_eval = X, labels
    
    sil = silhouette_score(X_eval, y_eval)
    db = davies_bouldin_score(X_eval, y_eval)
    ch = calinski_harabasz_score(X_eval, y_eval)
    counts = pd.Series(y_eval).value_counts()
    balance = counts.max() / counts.min()
    
    return {
        'silhouette': sil,
        'davies_bouldin': db,
        'calinski_harabasz': ch,
        'balance_ratio': balance,
        'n_clusters': n_clusters,
        'n_noise': int((labels == -1).sum()) if -1 in labels else 0
    }

4. Final Method: ISO_QT_PCA95_KMeans_k3

4.1 Method Selection Rationale

After comprehensive evaluation, we selected ISO_QT_PCA95_KMeans_k3 as the final clustering method based on the following criteria:

  1. Silhouette Score ≥ 0.40: Measures cluster cohesion and separation
  2. Balance Ratio ≤ 3.0: Ensures reasonably balanced cluster sizes
  3. Number of Clusters = 3: Matches business requirement
  4. Reproducibility: Consistent results across runs
  5. Interpretability: Clear business meaning for each cluster

4.2 Final Pipeline Implementation

The final pipeline consists of four steps:

  1. IsolationForest Outlier Removal: Removes ~8% of outliers (contamination=0.08)
  2. QuantileTransformer Normalization: Maps features to normal distribution
  3. PCA Dimensionality Reduction: Retains 95% of variance (5 components)
  4. KMeans Clustering: k=3 clusters with 100 initializations

5. Robustness Analysis

5.1 Bootstrap/Subsample Stability

We evaluated the stability of the final clustering method using bootstrap subsampling:

from sklearn.metrics import adjusted_rand_score as ARI
from sklearn.metrics import normalized_mutual_info_score as NMI

def run_pipeline(df, feature_cols, contamination=0.08, qt_distribution='normal', 
                 pca_var=0.95, k=3, random_state=42):
    """Run the complete clustering pipeline"""
    X = df[feature_cols].replace([np.inf, -np.inf], np.nan).fillna(0).values
    
    # Isolation Forest
    iso = IsolationForest(contamination=contamination, random_state=random_state)
    mask = iso.fit_predict(X) == 1
    X_iso = X[mask]
    
    # Quantile Transformer
    qt = QuantileTransformer(output_distribution=qt_distribution, random_state=random_state)
    X_qt = qt.fit_transform(X_iso)
    
    # PCA
    pca = PCA(n_components=pca_var, random_state=random_state)
    X_pca = pca.fit_transform(X_qt)
    
    # KMeans
    km = KMeans(n_clusters=k, n_init=100, max_iter=1000, random_state=random_state)
    labels = km.fit_predict(X_pca)
    
    # Metrics
    sil = silhouette_score(X_pca, labels)
    counts = pd.Series(labels).value_counts()
    balance = counts.max() / counts.min()
    
    return labels, {
        'mask_kept': mask,
        'silhouette': sil,
        'balance_ratio': float(balance),
        'n_clusters': int(len(np.unique(labels)))
    }

# Compute baseline
base_labels, base_info = run_pipeline(df, FEATURES, contamination=0.08, pca_var=0.95, k=3)
baseline_labels = np.full(len(df), fill_value=np.nan)
kept_idx = np.where(base_info['mask_kept'])[0]
baseline_labels[kept_idx] = base_labels

# Subsample stability analysis
def subsample_stability(df, feature_cols, n_runs=30, frac=0.8, random_state=42):
    rng = np.random.RandomState(random_state)
    sils, aris, nmis = [], [], []
    
    base_labels_array = baseline_labels.copy()
    
    for i in range(n_runs):
        idx = rng.choice(df.index.values, size=int(frac * len(df)), replace=False)
        df_sub = df.loc[idx].copy()
        labels, info = run_pipeline(df_sub, feature_cols, contamination=0.08, 
                                    pca_var=0.95, k=3, random_state=random_state + i)
        sils.append(info['silhouette'])
        
        if base_labels_array is not None:
            sub_kept_idx = df_sub.index.values[info['mask_kept']]
            valid_mask_global = ~pd.isna(base_labels_array)
            common_idx = np.intersect1d(sub_kept_idx, df.index.values[valid_mask_global])
            if len(common_idx) > 10:
                sub_map = {ix: lab for ix, lab in zip(df_sub.index.values[info['mask_kept']], labels)}
                y_sub = np.array([sub_map[ix] for ix in common_idx])
                y_base = np.array([base_labels_array[df.index.get_loc(ix)] for ix in common_idx])
                aris.append(ARI(y_base, y_sub))
                nmis.append(NMI(y_base, y_sub))
    
    return pd.DataFrame({
        'silhouette': sils,
        'ARI': aris if len(aris) > 0 else [np.nan] * len(sils),
        'NMI': nmis if len(nmis) > 0 else [np.nan] * len(sils)
    })

7. Evaluation Metrics

7.1 Internal Validation Metrics

We used three internal validation metrics to evaluate clustering quality:

  1. Silhouette Score: Measures cluster cohesion and separation (higher is better, range: -1 to 1)
    • Target: ≥ 0.40
    • Final result: 0.586
  2. Davies-Bouldin Index: Measures average similarity ratio (lower is better)
    • Final result: 0.706
  3. Calinski-Harabasz Score: Ratio of between-cluster to within-cluster variance (higher is better)
    • Final result: 4919.6

7.2 Cluster Balance

Balance Ratio: Ratio of largest to smallest cluster size (lower is better) - Target: ≤ 3.0 - Final result: 1.75:1 - Cluster sizes: {0: 621, 1: 1085, 2: 646}

7.3 Stability Metrics

Adjusted Rand Index (ARI): Measures agreement between clusterings (range: -1 to 1, 1 = perfect agreement) - Bootstrap mean: 1.0 (perfect stability)

Normalized Mutual Information (NMI): Measures mutual information between clusterings (range: 0 to 1, 1 = perfect agreement) - Bootstrap mean: 1.0 (perfect stability)
