3.2 Data Preprocessing Pipeline

The preprocessing pipeline consists of four main steps:

  1. Missing Value Handling: Fill missing values with 0
  2. Outlier Removal: Use IsolationForest to remove ~8% of outliers
  3. Normalization: Apply QuantileTransformer to map features to normal distribution
  4. Dimensionality Reduction: Apply PCA to retain 95% of variance
# Load enhanced features
df = df_enhanced.copy()
X = df[FEATURES].fillna(0)
print(f"Initial features shape: {X.shape}")

# Step 1: IsolationForest outlier removal
iso = IsolationForest(contamination=0.08, random_state=42)
inlier_mask = iso.fit_predict(X) == 1
X_clean = X[inlier_mask]
print(f"After outlier removal: {X_clean.shape[0]} samples (removed {len(X) - X_clean.shape[0]})")

# Step 2: QuantileTransformer normalization
qt = QuantileTransformer(output_distribution='normal', random_state=42)
X_qt = qt.fit_transform(X_clean)
print(f"After Quantile normalization: {X_qt.shape}")

# Step 3: PCA 95% variance
pca = PCA(n_components=0.95, random_state=42)
X_pca = pca.fit_transform(X_qt)
print(f"After PCA: {X_pca.shape[1]} components (explained variance: {pca.explained_variance_ratio_.sum():.3f})")

# Create performance tier benchmarks
def create_performance_tiers(df, metric, n_tiers=3):
    """Create performance tiers"""
    # Exclude zero values for tiering
    non_zero = df[df[metric] > 0][metric]
    if len(non_zero) == 0:
        return pd.Series(['Zero'] * len(df), index=df.index)
    
    # Use quantiles for tiering
    q33 = non_zero.quantile(0.33)
    q67 = non_zero.quantile(0.67)
    
    def assign_tier(value):
        if value == 0:
            return 'Zero'
        elif value <= q33:
            return 'Low'
        elif value <= q67:
            return 'Medium'
        else:
            return 'High'
    
    return df[metric].apply(assign_tier)

# Create tiers for key metrics

9.2 Key Insights

Based on the exploratory data analysis, we have identified several key insights:

  1. Data Quality: The dataset is relatively clean with minimal missing values after preprocessing. However, there is a significant data gap in advertising spend from October 2023 to May 2024.

  2. Feature Distributions: Most features show right-skewed distributions, indicating the presence of high-performing outliers. This supports the use of robust preprocessing techniques.

  3. Correlations: Sales are strongly correlated with website visits and unique lead count, suggesting that traffic and lead generation are key drivers of performance.

  4. Channel Preferences: Search and social media are the dominant advertising channels, with most stores using 1-2 primary channels.

  5. Temporal Patterns: The data shows seasonal variations, with higher performance in certain quarters.

  6. Dimensionality Reduction: PCA successfully reduces the feature space from 11 dimensions to 5 while retaining 95% of the variance, making the data more suitable for clustering.

These insights inform the subsequent clustering analysis and model development phases of the project.
